Selector de fecha y hora

El cliente rechazó las ruedas nativas y el scroll largo (RNF-08). Estos son los tres casos del sistema. Se manejan enteros con el teclado: flechas para moverse, PageUp y PageDown para cambiar de mes, Shift para saltar de a un año, Enter para elegir.
